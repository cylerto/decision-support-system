# Decision Support System

Информационная система поддержки принятия решений для малого предприятия. Помогает руководителю вести управленческий финансовый учёт, следить за бюджетом и видеть, как меняются ключевые показатели бизнеса.


## Возможности

- Учёт доходов и расходов с привязкой к статьям, подразделениям и проектам.
- Дашборд с финансовыми показателями и графиками.
- Аналитика прибыли, затрат и динамики операций.
- Сравнение бюджета с фактическими значениями.
- Прогнозирование финансовых показателей и оценка рисков.
- Рекомендации на основе финансовых правил; AI-интерпретация при настройке внешнего API.
- Импорт и экспорт данных в CSV/XLSX.
- Пользователи, разграничение доступа и журнал действий.

## Технологии

| Часть | Стек |
| --- | --- |
| Frontend | React 19, React Router, Vite, Chart.js |

Приложение построено как React SPA и Flask API. Бизнес-расчёты вынесены в отдельные модули backend.

## Запуск локально

Понадобятся Python 3.10+ (рекомендуется 3.11), Node.js с npm и PostgreSQL.

1. Создайте базу данных PostgreSQL и настройте строку подключения.
2. Создайте `.env` в корне проекта на основе `.env.example`. Укажите `DATABASE_URL` и уникальный `SECRET_KEY`. Для AI-функций добавьте ключ выбранного провайдера.
3. Установите зависимости backend и frontend:

   ```powershell
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r backend\requirements.txt
   npm install
   npm --prefix frontend install
   ```

4. Запустите сервер и клиент из корня проекта:

   ```powershell
   npm run dev
   ```

Vite обслуживает интерфейс, а запросы `/api` перенаправляются на Flask (`http://localhost:5000`). Для отдельного запуска используйте `npm run dev:frontend` или `npm run dev:backend`.

> При первой настройке проверьте схему и миграции в `backend/sql/`. Автоматическое создание таблиц выключено по умолчанию (`AUTO_CREATE_DB=0`). Не публикуйте `.env` и реальные API-ключи.

## Назначение и ограничения

Система предназначена для управленческого учёта и поддержки решений. Она не заменяет бухгалтерскую программу и регламентированную бухгалтерскую отчётность. Прогнозы и рекомендации следует рассматривать как вспомогательную аналитику.
