# Предзащита: Чек-лист запуска

## 1) Быстрый старт

1. Установить зависимости:
   - `pip install -r backend/requirements.txt`
   - `npm --prefix frontend install`
2. Запустить проект:
   - `npm run dev`
3. Проверить здоровье:
   - `http://127.0.0.1:5000/api/health` -> `status: ok`

## 2) Демо-аккаунты

- `coffee_owner` / `Coffee2026!`
- `coffee_manager` / `Manager2026!`
- `coffee_accountant` / `Accountant2026!`
- `coffee_department` / `DeptHead2026!`

## 3) Быстрый smoke перед показом

- Выполнить:
  - `python -m backend.smoke_predefense`
- Ожидаемо:
  - owner видит операции
  - owner может добавить/удалить расход
  - manager видит те же данные, но не может удалять
  - аналитика и рекомендации доступны

## 4) Если таблица операций пустая в UI

1. Нажать `Сбросить фильтры` на вкладке операций.
2. Сделать `Ctrl + F5`.
3. Перелогиниться.

## 5) Критично для защиты

- Работать из одного профиля БД (`decision_support`).
- Не менять вручную `DATABASE_URL` во время показа.
- Перед показом не запускать миграции/скрипты очистки.
